# Decisions

## 2026-11-23 — MeetTogether user count is typed in by hand
- **Chosen:** a static shields.io badge (`MeetTogether users-5`), the same style as the live MusicMax one. Update the number by hand in `tools/readmes.mjs` and `README.md`.
- **Why:** the store hides 18+ listings from anyone who isn't logged in (it serves an empty page), so shields.io's live `chrome-web-store/users` badge only says "not found". **Rejected:** the live badge (can't work); a hand-made SVG file (another file to keep in sync, and it doesn't match the other badges); scraping while logged in (would mean storing a Google login in CI).

## 2026-11-21 — Meadow is the main README
- **Chosen:** README.md = the meadow world (replaces ocean, chosen 2026-11-17).
- **Why:** the user's new pick. **Rejected:** ocean, still one click away under "pick a world". **Affects:** `MAIN` in `tools/readmes.mjs`.

## 2026-11-17 — Ocean is the main README
- **Chosen:** README.md = the ocean world; every version ends with "pick a world" (collapsible sections) so the others stay one click away.
- **Why:** the user's pick after seeing all versions. **Affects:** `MAIN` in `tools/readmes.mjs`.

## 2026-11-17 — Text-only project cards, small icons only
- **Chosen:** no screenshots in project cards; a 40 px icon when the project has a good one (copied into `assets/icons/` so it never breaks).
- **Why:** a weak or AI-looking screenshot hurts more than no picture. **Rejected:** the MeetTogether cartoon screenshot.

## 2026-11-17 — Everything is SVG made by code
- **Chosen:** each scene is an animated SVG generated by `tools/` (ASCII characters + shapes + CSS animation). The name is drawn from Instrument Serif turned into ASCII by coverage.
- **Why:** GitHub READMEs can't run JavaScript or page CSS, but SVG images can carry their own CSS animations. Generated from code, so the name and colors can change and be rebuilt.
- **Rejected:** GIFs (heavier, blurry, no transparency), hand-drawn characters from shapes (looked like stick figures), copyrighted manga art (public page).
- **Rule:** the font travels with its license (`tools/fonts/OFL.txt`). Dark text on a light background needs a denser character ramp to read.
